What it is

One container

Bring any public Docker image and tell us its port. Add env vars and secrets (encrypted) in the dashboard, YAML, or CLI.

Optional database and storage

Tick a box and we create a private MySQL database and an S3-compatible storage bucket. You map their connection details to env vars for your app.

HTTPS included

Every app gets a generated subdomain with an automatic Let’s Encrypt certificate.

How it works

1

Request access

Request access with your email. If your account is approved, a PicoPaaS platform admin will reach out, usually within a day.

2

Create an app

Image, port, env vars, and a database or bucket if you need one.

3

Open your URL

Live in about a minute over HTTPS. Edit the config to redeploy.

You’ll need a public Docker image that doesn’t run as root.

# 1. push an image to any public registry
docker push ghcr.io/you/app:1.0
# 2. create an app: image ghcr.io/you/app:1.0, port 8080
# 3. open the URL we generate
https://<generated-name>.raisehellpraisedale.xyz
