container hosting for hobby projects

Ship a container. Get a URL, a database, a bucket, and backups.

Point PicoPaaS at a public Docker image and a port. You get an HTTPS address within about a minute, and can add a managed PostgreSQL or MySQL database and an S3-compatible bucket with a checkbox each. Nightly backups cover them. Made for demos, experiments, and class projects.

Request accessLog in

Images must be public and run as non-root. Access is approved manually.

What it is

One container, your way

Any public image that runs as non-root, plus its port. Set env vars and encrypted secrets from the dashboard, CLI or API.

PostgreSQL or MySQL

Pick either engine per app. Each app gets its own database (50 MB), and can add an S3-compatible bucket (100 MB). Credentials arrive as env vars.

HTTPS included

Every app gets a generated subdomain with an automatic Let’s Encrypt certificate. Bring your own domain if you prefer.

Nightly backups

Your database, bucket and volume are backed up each night, encrypted and stored outside the cluster. Back up now or download a backup any time. Restores go through an admin for now.

Backups are bounded and capped per app, and don’t count against your quotas. Details in the guide.

Also included

  • Templates and recipes. One-click starters for Ghost, WordPress, Directus, Grafana, n8n, Shlink, Gatus and an nginx static site.
  • Safe deploys. Roll back with one click; a new image that fails to start is reverted automatically.
  • Kaisen (in preview). Describe an app and have Claude build and deploy it for you.
  • Teams. Share apps with others in a project.
  • Your tools. A CLI, API keys, your own domain with automatic TLS, and an audit log.
  • Visibility. Live status, logs, restarts, and recent CPU and memory history.
  • Isolation. Apps are walled off from each other and from the platform.

Build with Kaisen (in preview)

Describe a small app in plain words. Kaisen (Claude) writes it, deploys it into your project as a normal app, and changes it when you tell it what to change. For example, it built a Markdown notes app with a nested page tree, MySQL storage, image uploads and dark mode in one run, for about five US cents on Claude Haiku 5.5.

Your key, your caps

Bring your own Anthropic API key and set spend caps per project.

A normal app

It lands in your personal or team project with a “Built with Kaisen · Preview” pill, and counts against the project’s app limit. Add an optional MySQL database.

Iterate by typing

Tell it what to change and it redeploys. Take an app offline and deploy it again later.

Your code stays yours

Download the code plus the full conversation (CONVERSATION.md), or push each build to its own GitHub repo.

Kaisen is in preview and meant for small apps. It doesn’t run its generated tests yet, has no web access yet, and previews have no blob storage, secrets or email. How to use Kaisen.

How it works

1

Request access

Sign up with your email. If approved, a platform admin will reach out, usually within a day.

2

Create an app

Image, port, env vars, and a PostgreSQL or MySQL database or bucket if you need one.

3

Open your URL

Live in about a minute over HTTPS. Edit the config to redeploy.

You’ll need a public Docker image that doesn’t run as root.

# 1. push an image to any public registry
docker push ghcr.io/you/app:1.0
# 2. create an app: image ghcr.io/you/app:1.0, port 8080
# 3. open the URL we generate
https://<generated-name>.picopaas.xyz
