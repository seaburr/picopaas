Tiny hosting for throwaway projects

A small Heroku-like platform. Push one container image, get HTTPS on your own subdomain, with an optional MySQL database and S3-compatible bucket.

Request access

What it is

One container

Bring a Docker image and a port. Set env vars and secrets (encrypted at rest) in the dashboard or API.

Optional MySQL + bucket

Tick a box and get a private database and an object-storage bucket, wired in as env vars.

HTTPS included

Every app gets its own subdomain with an automatic Let's Encrypt certificate.

How it works

1

Request access

Sign up and wait for approval.

2

Create an app

Point at your image, set the port and env vars, pick a database or bucket if you need one.

3

Open your URL

The platform deploys it and serves it over HTTPS. Update the config to redeploy.
